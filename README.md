# 野性档案 SAVAGE ARCHIVE

> 一座运行在公网上的自由图片展览馆 · 策展人 **24.savage**

在线访问：<https://24savage-cell.github.io/24-/>

## 功能

- **图片展览**：瀑布流展厅、灯箱浏览、编号展签、点赞、排序（最新/最热）与筛选（馆藏精选/观众投稿）
- **邮箱验证码登录**：注册 / 验证码登录，可选密码（PBKDF2 加盐哈希，12 万次迭代）
- **人机验证（CAPTCHA）**：Canvas 图形验证码（扭曲字符 + 干扰线 + 噪点）+ 行为分析（鼠标轨迹 + 时间检测）+ 一次性令牌防重放
- **自由投稿**：已登录用户可用昵称署名，或匿名上传；投稿前需通过人机验证
- **安全加固**：PBKDF2 密码哈希、邮箱格式校验、一次性令牌防重放、限频（发送验证码 3 次/10 分钟、上传 5 次/分钟）、输入校验与 XSS 转义
- **双模存储**：默认云同步（jsonblob 公共 JSON 存储，全球共享）；云端不可达时自动降级为本机模式（localStorage）
- **分享**：右上角状态点可复制展厅链接（`#g=<展厅ID>`），他人打开即连接同一云端展厅

## 技术架构

| 层 | 方案 |
| --- | --- |
| 托管 | GitHub Pages（静态、免费、全球 CDN） |
| 图像存储 | 浏览器直传 jsonblob（单作品一个 blob，JPEG ≤ 900KB） |
| 索引/账号 | jsonblob 单 blob 索引（缩略图 + 元数据 + PBKDF2 哈希账号） |
| 邮件服务 | EmailJS（免费 200 封/月）或 FormSubmit（免注册） |
| 人机验证 | 自建 Canvas 图形验证码 + 行为分析 + 一次性令牌 |
| 兜底 | localStorage 本机模式 |

无后端、无构建步骤、无追踪。

## 邮件服务配置（首次使用必需）

1. 打开网站，点击顶栏 **「安全」** 按钮
2. 选择一种邮件服务：
   - **EmailJS（推荐）**：注册 emailjs.com → 添加邮箱服务 → 创建模板（变量：`to_email` / `code` / `to_name` / `subject`）→ 填入 Service ID / Template ID / Public Key
   - **FormSubmit**：填入你的收件邮箱，首次使用需到该邮箱点击确认激活链接（仅一次）
3. 点击「保存配置」→ 点击「测试发送」验证
